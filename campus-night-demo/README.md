# 凌晨三点，校园还亮着

Three.js 卡通 3D 网页游戏。每局上限 12 分钟。先在操场学会抢修，再守住看台的两次袭线。球场第一波结束后，由玩家决定何时开始第二波。清掉威胁并让三盏灯同时亮满 15 秒即可通关。

怪物进入已割除的地块时会留下嫩芽，约 3 秒后变回杂草。嫩芽长成前可以开过去清除。重新长成的杂草会切断该格的供电，备用路线仍可继续供电。「加装压草轮」会暂时保护玩家经过的草径。

袭线前会标出来袭入口、走向和目标路灯。可以在半路击退怪物、提前铺好备用线，或等它撤离后抢修。主线路断开时，已有的备用线会继续供电。

## 本地试玩

需要 Node.js 20.19+ 或 22.12+。在项目目录运行：

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址。电脑使用 WASD 或方向键，手机在操场上按住并拖拽。园丁会自动割草和攻击，按 Esc 或页面上的「暂停」可以休息。

## 构建和部署

```sh
npm run build
npm run preview
```

`dist/` 是完整的静态站点。预览命令可以验证构建包；部署时将整个目录的内容一起上传，保持 `index.html` 与 `assets/` 的相对位置。部署后的游戏无需后端或外部模型资源。

- `game.js` 保留割草、相邻地块供电、怪物、三阶段流程和页面操作。
- `scene.js` 将逻辑状态映射到正交镜头、草簇、供电线路和灯光。
- `models.js` 在网页端生成园丁、怪物、配电箱、路灯和场景模型。
